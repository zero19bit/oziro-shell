# Product vision

Oziro is an independent Linux desktop environment, initially targeting Arch Linux and Wayland. The goal is a cohesive, low-resource, approachable desktop with its own identity, not a collection of compositor config files. Long-term: Oziro OS, an installable Linux distribution, after the desktop is mature. A custom kernel or compositor is not required for independence.

## Product pillars
- Native responsive interaction: quick menus, useful system controls, a real settings application, predictable launch and session lifecycle.
- Identity: restrained macOS-inspired polish without copying proprietary logos, assets or pretending to be macOS. Oziro's own mark, coordinated theme packs and wallpapers.
- Efficiency: event-driven core, low idle CPU/RAM, optional effects and adaptive energy policy. Treat energy savings as measurements, not promises.
- Control: user-owned settings, optional dock/widgets/extensions, offline-first defaults, accessible keyboard and mouse interactions.
- Trust: real lock protocols and system authentication, no hidden actions, honest unavailable states, easy rollback.

## Scope
Desktop v1.0: reliable daily-use desktop session with system settings, launcher, dock, core system controls, secure lock/idle/suspend, notifications, integration and recovery. Advanced AI assistant and extension SDK are later opt-in features. Distribution ISO, packaging, updates, hardware installation and branding require a separate release gate. Do not confuse a standalone SDDM entry with a standalone OS.
